# 공유받은 Firebase 프로젝트에 보호자 앱 등록 → Android FCM 테스트 메시지 받기

> 작성일: 2026-11-25 · 대상: 보호자 앱 담당자 (콘솔에서 직접 진행)
> 목표: **서버가 완성되기 전에** 팀원 프로젝트에서 보호자 앱(Android)이 실제 원격 푸시를 받는지 확인한다.
> 원칙: 기존 설정·데이터·보안 규칙·Functions는 **건드리지 않는다.** 이 안내에서 프로젝트에 생기는 변화는 **① 보호자 Android 앱 등록**(+ 선택: iOS 앱 등록)과 **② 테스트 메시지 초안**뿐이며, ②는 마지막에 지운다.

---

## 0단계. 시작 전에 프로젝트 소유자(팀원)에게 한 줄 동의 받기
> "보호자 앱을 프로젝트에 앱으로 등록(Android `com.yju.haebom.guardian_app`, 필요하면 iOS `com.yju.haebom.guardianApp`)하고, 콘솔에서 내 폰으로 FCM 테스트 메시지만 보내 볼게. 규칙·데이터·함수는 안 건드려."

앱 등록은 프로젝트 설정에 앱이 하나 추가되는 변경이라 소유자 동의가 필요하다.

---

## 1단계. 프로젝트와 내 권한 확인 (변경 없음)
1. https://console.firebase.google.com 에서 팀원이 공유한 프로젝트를 연다.
2. 왼쪽 위 **톱니바퀴 → 프로젝트 설정 → 일반** 탭
   - **프로젝트 ID**, **프로젝트 번호**를 메모한다 (번호 = FCM Sender ID).
3. 왼쪽 아래 요금제 표시 확인: **Spark** 또는 **Blaze**
   - Blaze여도 나는 아무것도 가입·결제하지 않는다. 결제는 소유자 계정 것이며, FCM 발송은 무료다.
4. **프로젝트 설정 → 사용자 및 권한** 탭에서 내 역할 확인
   - **뷰어**면 앱을 등록할 수 없다 → 소유자에게 2단계를 대신 해 달라고 하거나 권한 상향을 요청한다.
5. **프로젝트 설정 → 일반 → 내 앱** 목록 확인
   - `com.yju.haebom.guardian_app`이 이미 있으면 2단계는 건너뛰고 그 앱의 `google-services.json`만 받는다.

## 2단계. 보호자 Android 앱 등록 (변경: 앱 1개 추가)
1. **프로젝트 설정 → 일반 → 내 앱 → "앱 추가"** → **Android** 아이콘
2. 입력
   - Android 패키지 이름: **`com.yju.haebom.guardian_app`** (한 글자도 다르면 안 됨)
   - 앱 닉네임: `해봄 가족 Android` (자유)
   - 디버그 서명 인증서 SHA-1: **비워 둔다** (익명 로그인·FCM에는 필요 없음)
3. **앱 등록** → **google-services.json 다운로드**
4. "Firebase SDK 추가" 단계는 **건너뛴다** (다음 → 다음 → 콘솔로 이동). 보호자 앱 코드에 이미 들어 있다.
5. 다운로드한 파일은 **저장소 폴더에 넣지 말고**, Claude에게 **파일 위치만** 알려 준다 (예: `~/Downloads/google-services.json`).
   Claude가 필요한 값 4개만 `config/firebase.json`(Git 제외)에 옮긴다.

## 3단계. FCM API 확인 (변경 없음)
1. **프로젝트 설정 → 클라우드 메시징** 탭
2. **Firebase Cloud Messaging API (V1)** 가 "사용 설정됨"인지 본다.
   - "사용 중지됨"이면 직접 켜지 말고 소유자(또는 서버 담당자)에게 요청한다.

## 4단계. 익명 로그인 상태 확인 (변경 없음)
1. **빌드 → Authentication → Sign-in method** 탭에서 **익명**이 사용 설정인지 본다.
2. 꺼져 있어도 **켜지 않는다** (서버 담당자·소유자와 합의할 일).
   - 꺼져 있으면 보호자 앱은 "로그인하지 못했습니다" 화면을 보여 주지만, **그 화면에서도 FCM 토큰이 나오므로 테스트 메시지는 받을 수 있다.**
   - 이때 Firestore 데이터(알림 목록 등)는 볼 수 없다. 서버·규칙이 준비된 뒤에 확인한다.

## 5단계. 폰에서 보호자 앱 실행 (Claude가 함)
1. 폴드3를 Mac과 연결해 두면 Claude가 `config/firebase.json`으로 **서버 모드 디버그 빌드**를 설치·실행한다.
2. 폰에서 **알림 권한 → 허용**
3. **FCM 등록 토큰**은 Claude가 실행 로그에서 읽어 알려 준다.
   - 폰에서 직접 복사하려면: (로그인 성공 시) **⚙︎ 설정 → 원격 알림 → "FCM 토큰 복사 (테스트용)"** / (로그인 실패 시) 오류 화면의 **"토큰 복사"**
   - 이 토큰은 **디버그 빌드에서만** 보이며, 테스트가 끝나면 공유하지 않는다.
   - 설정 화면의 "원격 알림"은 서버가 없어서 **"서버 연결 대기"**로 보이는 것이 정상이다.

## 6단계. 콘솔에서 테스트 메시지 보내기 (변경: 캠페인 초안 생성 → 7단계에서 삭제)
1. 왼쪽 메뉴 **실행(Run/Engage) → Messaging** (메뉴 위치는 콘솔 개편에 따라 "모든 제품"에서 찾을 수 있음)
2. **"첫 번째 캠페인 만들기"** 또는 **"새 캠페인"** → **Firebase 알림 메시지** → 만들기
3. 입력
   - 알림 제목: `해봄 가족`
   - 알림 텍스트: `새 가족 알림이 도착했습니다.` (잠금 화면 최소 문구와 같게)
4. 오른쪽 **"테스트 메시지 전송"** → **FCM 등록 토큰 추가**에 5단계 토큰 붙여 넣기 → **+** → 체크 → **테스트**
5. ⚠️ **"검토"·"게시"는 누르지 않는다.** 게시하면 프로젝트의 다른 앱 사용자에게도 발송될 수 있다.

### 확인할 상황 (한 번에 하나씩, 매번 6-4의 "테스트"를 다시 누름)
| # | 폰 상태 | 기대 결과 |
|---|---|---|
| 1 | 보호자 앱이 **화면에 열려 있음** | 앱이 직접 알림 배너 표시 (Android는 앱이 앞에 있으면 FCM 알림을 자동으로 띄우지 않아 앱이 대신 띄움) |
| 2 | **홈 화면으로 나감** (앱은 백그라운드) | 상단 알림 팝업·알림창에 표시 |
| 3 | **화면을 끄고 잠금** | 잠금 화면에 표시 (최소 문구) |
| 4 | **최근 앱 목록에서 쓸어서 닫음** | 알림창에 표시 |
| 5 | 알림을 **누름** | 보호자 앱이 열림 (콘솔 메시지에는 문서 ID가 없어 상세 화면이 아니라 홈이 열림 — 서버 메시지에서는 상세로 이동) |

- **설정 → 앱 → 강제 중지**한 상태에서는 Android 정책상 FCM을 받지 못한다. 다시 앱을 한 번 열면 된다.
- 삼성 폰 알림 팝업이 작게 보이면: 설정 → 알림 → 알림 팝업 스타일 → "자세히"
- 안 오면: 알림 권한, 배터리 최적화(해봄 가족 → 제한 없음), Wi-Fi, 토큰을 정확히 붙였는지 확인

## 7단계. 정리
1. **Messaging 캠페인 목록**에서 방금 만든 **초안(Draft)을 삭제**한다 (프로젝트에 흔적을 남기지 않기).
2. 등록한 보호자 앱은 **그대로 둔다** (서버 연동에 필요).
3. 결과(1~5번 상황별 수신 여부)를 Claude에게 알려 주면 `PROGRESS.md` 실행 검증 표에 기록한다.

## (선택) iOS 앱 등록 — iPhone에서 실제 서버 데이터를 보려면
- 프로젝트 설정 → 내 앱 → 앱 추가 → **iOS** → 번들 ID **`com.yju.haebom.guardianApp`** → `GoogleService-Info.plist` 다운로드 → 위치만 Claude에게 알려 주기 (SDK 추가 단계는 건너뜀)
- iPhone은 **APNs 키(Apple 유료 계정)** 가 없어 **원격 푸시 테스트는 할 수 없다.** 클라우드 메시징 탭의 "Apple 앱 구성"은 비워 둔다.
- 등록해 두면 서버·보안 규칙이 준비된 뒤 iPhone에서 알림 목록·승인·연결을 실제 데이터로 확인할 수 있다 (앱이 켜져 있을 때 로컬 알림).
